Para inicializar aplicacion abrir build.sh desde consola (./build.sh)

COMANDOS:

comandos de sistema deberian de funcionar de la misma forma que en terminal

miprof ejec comando arg1 arg2 arg3...                           Ejecuta comando miprof con parametro ejec
miprof ejecsave archivo comando arg1 arg2 arg3...               Ejecuta comando miprof con parametro ejecsave y guarda todo en archivo
miprof ejecutar maxtiempo comando arg1 arg2 arg3...             Ejecuta comando miprof con parametro ejecutar y lo temina si este excede maxtiempo
ingresar maxtiempo con punto decimal (0, 1, 2.2, 0.1, 1.0)
